# Relink Color Graded Footage for After Effects by WoWa

Автоматический скрипт для замены исходных видеофайлов на покрашенные (грейденные) версии в Adobe After Effects. Идеально подходит для пайплайна: монтаж в AE (Premiere) → грейдинг в DaVinci Resolve → возврат в AE.

## ✨ Возможности

- 🎯 **Автоматическая перелинковка** - заменяет файлы по суффиксу (например, `video.mp4` → `video-cc.mp4`)
- 🛡️ **Безопасность** - все эффекты, маски, ключевые кадры и настройки слоев сохраняются
- 🎬 **Умный выбор** - работа с файлами из конкретной папки Project и композиции
- 🔍 **Проверка использования** - скрипт проверяет, какие файлы реально используются в композиции
- 💾 **Undo support** - все изменения можно отменить одной командой Ctrl+Z
- 🖥️ **Кроссплатформенность** - работает на Windows и macOS
- 🚫 **Защита от дублей** - пропускает файлы, которые уже имеют суффикс

## 📥 Установка

### Способ 1: Установка в панель (рекомендуется)

1. Скачайте файл `RelinkColorGraded.jsx`
2. Скопируйте его в папку скриптов After Effects:

**Windows:**
C:\Program Files\Adobe\Adobe After Effects [VERSION]\Support Files\Scripts\ScriptUI Panels\

**macOS:**
/Applications/Adobe After Effects [VERSION]/Scripts/ScriptUI Panels/


3. Перезапустите After Effects
4. Откройте через меню: **Window → RelinkColorGraded**

### Способ 2: Разовый запуск

1. Скачайте файл `RelinkColorGraded.jsx`
2. В After Effects: **File → Scripts → Run Script File...**
3. Выберите скачанный файл

### ⚠️ Важная настройка

Перед использованием разрешите скриптам доступ к файлам:

1. **Edit → Preferences → Scripting & Expressions** (Windows)
2. **After Effects → Preferences → Scripting & Expressions** (macOS)
3. ✅ Поставьте галочку **"Allow Scripts to Write Files and Access Network"**

## 🚀 Как использовать

1. **Запустите скрипт** через окно Window или File → Scripts

2. **Введите суффикс** - текст, который добавляется к имени файла
   - Пример: если `C0100.MP4` → `C0100-cc.MP4`, введите `-cc`

3. **Выберите композицию** - нажмите "Выбрать" и укажите композицию с вашим роликом

4. **Выберите папку в Project** - папку с исходными файлами в панели Project

5. **Выберите папку на диске** - папку, куда вы экспортировали покрашенные файлы из DaVinci Resolve

6. **Нажмите "ПЕРелиНКОВАТЬ"** - скрипт автоматически заменит файлы

## 📊 Пример работы

**Исходные файлы:**
- `video-test.mp4`
- `video-test-02.mp4`

**Покрашенные файлы (в папке):**
- `video-test-cc.mp4`
- `video-test-02-cc.mp4`

**Суффикс:** `-cc`

**Результат:** Все слои в композиции автоматически переключатся на покрашенные версии, сохраняя все эффекты и ключи!

## 🛡️ Безопасность

- ✅ **Все эффекты сохраняются** - меняется только источник файла
- ✅ **Длительность не обрезается** - сохраняются все настройки импорта
- ✅ **Undo support** - нажмите Ctrl+Z для отмены всех изменений
- ✅ **Проверка файлов** - скрипт предупреждает, если файлы не найдены
- ✅ **Защита от дублей** - пропускает файлы, которые уже имеют суффикс

## 📋 Лог работы

Скрипт выводит подробный отчет:
- Сколько файлов успешно заменено
- Какие файлы пропущены (уже с суффиксом, офлайн, не используются)
- Какие файлы не найдены в папке

## 🐛 Решение проблем

### Скрипт не видит файлы
- Проверьте, что суффикс введен правильно (чувствителен к регистру)
- Убедитесь, что файлы лежат в выбранной папке
- Проверьте разрешения на чтение папки

### Ошибка "Script does not have a value"
- Убедитесь, что выбрана композиция
- Проверьте, что в папке есть файлы
- Перезапустите After Effects

### Файлы не заменяются
- Проверьте настройку "Allow Scripts to Write Files and Access Network"
- Убедитесь, что файлы не офлайн
- Проверьте права доступа к файлам

### Скрипт не запускается
- Убедитесь, что файл лежит в правильной папке (`ScriptUI Panels`)
- Перезапустите After Effects
- Проверьте, что имя файла заканчивается на `.jsx`
